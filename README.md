# 💤 Vim Dotfiles

## Getting Started

### Requirements
Install these packages before install this repository:
- [git](https://git-scm.com/install/windows) 2.53.0 or above
- [curl](https://curl.se/download.html) 8.18.0 or above

### Installation
Run this command on your terminal to install:
```
curl -fsSL https://raw.githubusercontent.com/ViniUme/vim-dotfiles/refs/heads/main/install.sh | sh
```
